# CantHarm 2026-04-02 Public Release

This GitHub release mirrors the CantHarm 2026-04-02 locked public release for reviewer-facing access and verification.

## Contents

- 4,823 forms
- 6,365 senses
- 4,823 canonical audio clips
- 11 speaker IDs
- One canonical audio clip per retained form
- Release manifest, workbook, metadata bundle, statistics, benchmark highlights, audio inventory, and 11 speaker audio packages

## Verification

Use the attached `PACKAGE_SHA256SUMS.txt` and `PACKAGE_MANIFEST.json` files to verify downloaded assets.

## License Summary

- Workbook and tabular release files: CC BY 4.0 with the dictionary-derived source-text caveat
- Audio files: CC BY 4.0 with speaker consent for this research dataset release
- Code and lightweight scripts, if any are added later: MIT

## Acceptable-Use And Ethics Guidance

The release is accompanied by acceptable-use and ethics guidance asking users not to use audio for speaker recognition, voice cloning, biometric modeling, re-identification, or demographic inference. This guidance is separate from the CC BY 4.0 license grant.

CantHarm contains harmful and offensive lexical material and waveform audio. It is intended for research and benchmark analysis, not production moderation or punitive decision-making.
