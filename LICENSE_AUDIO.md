# Audio License

CantHarm audio is approved for CC BY 4.0 release with speaker consent.

## Scope

The current release contains 4,823 canonical audio clips, one clip per retained form, organized by 11 pseudonymous speaker IDs.

## Attribution

Users should cite CantHarm and state:

`2026-04-02 public release`

## Ethics Guidance

The following are unacceptable uses:

- speaker recognition
- biometric modeling
- voice cloning
- speaker re-identification
- demographic inference from voice

This ethics guidance is not an additional downstream license restriction that contradicts CC BY 4.0; it documents expected responsible use.
