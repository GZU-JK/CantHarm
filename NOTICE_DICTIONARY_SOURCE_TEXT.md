# Notice: Dictionary-Derived Source Text

CantHarm links lexical forms and senses from source dictionaries and related lexical resources.

Open release scope:

- derived labels
- metadata
- source references
- benchmark statistics
- public file inventory

Outside open-license scope unless source-specific permissions are confirmed:

- dictionary-derived definitions
- source text copied or closely derived from dictionaries
- other source-specific text whose redistribution status is not confirmed

Users must not treat all dictionary-derived text as unconditionally CC BY 4.0.
